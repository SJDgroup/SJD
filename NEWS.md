# SJD 1.0.1

* `sjdWrap()` gains a new `useNewestVersion` argument, passed through to `getMatch()`, to control whether the newest Ensembl version is used for gene matching. Default is `FALSE`, matching previous behavior.
* Changed the default Ensembl version used in `getMatch()` from Aug 2020 (discontinued) to May 2025.
